# 2026-10-13 고정 과업의 현재 HB 재시험

- 사이트당 정확히1회, 독립 Luna(gpt-6-luna, medium), fork none, 동시 수행1명.
- 프로젝트 `D:/APPs/hyper-browsing/SKILL.md`를 읽고 그 프로젝트 launcher만 계측 wrapper로 사용. 설치된 스킬 사본/다른 제품/직접 Playwright/CUA/웹 검색/외부 HTTP 금지.
- 매 사이트 새 프로필·daemon, 최초 headless, 1440×900, en-US. 접근 제한 시 그 사이트만 headed로 복구. 다음 사이트는 새 headless 프로필. CAPTCHA 우회/사람 개입 없음. headed에서도 막히면 blocked 보고.
- 학습·자산 생성/수정/승격 OFF. 제품 코드는 전체 실험 동안 동결. root는 관찰·기록만 하며 수행자에게 사이트 해법을 주지 않는다.
- 첫 브라우저 명령부터8분 또는45호출. 준비·정리 시간은 별도. 원래 과업의 구매/예약/게시/장바구니 금지 유지.
- Luna는 중간 보고·질문 없이 수행에 집중하고 최종 결과만 저장. root가 명령/응답 로그를 보며 사용자 진행 보고와 과정 분석을 담당한다.
- 각4체크포인트는 현재 페이지 증거로 판정. 4/4만 성공. 제한·부분완료·불명은 구분. 가격/날씨/평점 자체의 과거 일치는 요구하지 않는다.
- 전체시간, CLI시간, 호출수, 완료조작, 오류, headed 전환, 생성된 stdout/stderr 바이트와 실제 세션 도구 전달 텍스트 바이트를 구분하고 중복조회/국소복구를 기록. 출력 잘림 때문에 생성된 stdout 전체가 LLM에 전달됐다고 가정하지 않는다. 명령 사이 시간을 순수 사고시간이라 부르지 않는다. 토큰은 실제 제공될 때만 보고한다.
