# Walmart 실전 검사 결과

- **판정:** 중단, 0/4 완료
- **첫 관찰:** Walmart 홈 URL에서 HTTP 200 및 제목 “Walmart | Save Money. Live better.” 확인. 사람 인증(CAPTCHA) 화면이 나타나 검색 과업을 시작하지 못함.
- **검색 / 정렬 / 상세 진입 / 상품 정보:** 모두 미확인. 상품명·가격·배송 조건을 확인하지 못함.
- **자동 폴백:** 첫 세션은 headless에서 headed로 전환했지만 CAPTCHA가 남아 있었다. 우회나 재시도 없이 중단했다.

CLI는 기록상 4회 실행됐다. 1번 홈 열기는 21.46초, 2번은 세션 ID를 알 수 없어 입력한 `pending` 조회로 실패(0.09초), 3번 홈 열기는 2.55초, 4번 세션 닫기는 0.12초였다. 첫 명령의 실제 세션 ID는 `task_cf782b5e8e80`, 재오픈 세션은 `task_674ad9293ad1`이었다. 두 번째 세션은 정상 종료했다. cleanup은 완료됐다. cleanup 뒤 첫 세션을 닫으려는 추가 명령은 런타임의 “Trial already cleaned” 차단으로 실행되지 않았다. 러닝 비활성 상태였고 `eval`은 0회다. 사전 준비부터 cleanup까지 약 2분 1초가 기록됐다. 순수 사고 시간은 측정할 수 없다.

CAPTCHA로 과업을 진행할 수 없어, Walmart 실전 검사는 여기서 종료했다.
