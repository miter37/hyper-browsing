# 실험에서 확인한 개선 후보

제품 코드는 측정 중 수정하지 않았다. 아래는 독립 시행의 관찰과 소스 확인에 근거한 후속 개발 후보이며, 사이트 차단까지 해결한다고 주장하지 않는다. 명령 번호는 해당 시행의 `command-NNN.json`을 가리킨다. 공개용 최소 증거는 `evidence.json`에 있고 원시 출력은 로컬에 보존한다.

| 우선순위 | 관찰 | 근거 | 제안 및 검증 방법 |
|---|---|---|---|
| P0 | 스냅샷 DOM 순회가 예외로 끝나 CAPTCHA 판독과 자동 폴백으로 이어지지 못함 | `r3_walmart_hb` 명령 002: `TypeError: n.children is not iterable`; 명령 004 스크린샷은 사람 확인 화면. `src/engine/page-state.ts`의 순회는 `n.children`을 바로 반복 | 노드·컬렉션 접근을 방어하고 관찰 일부 실패를 구조적으로 반환. 변형된 DOM과 빈 문서에서 순회가 전체 관찰을 중단하지 않는 회귀 테스트. 실제 원인은 별도 재현 필요 |
| P1 | PowerShell에서 따옴표 없는 `@e…` 참조가 인자에서 사라짐 | 여러 B 시행의 `invalid_target/not_started`. 스냅샷의 요소가 존재해도 참조 전달이 실패함 | Windows 명령 예시를 `'@e123'`로 수정하거나 셸 안전한 다른 참조 표기 제공. PowerShell을 실제로 거치는 인자 전달 테스트 |
| P1 | 정상 검색 필터·읽기 링크가 외부 쓰기로 분류됨 | Best Buy 링크 및 eBay Buy It Now 필터에서 확인 요구. `src/engine/risk.ts`의 단어 부분 일치와 href 포함 문맥 검사 | 도메인에 포함된 buy와 검색 필터를 구매 버튼과 구별. 국가 선택·상품 상세 읽기·구매 확정 각각의 회귀 사례로 확인. 위험한 실제 쓰기 보호는 유지 |
| P1 | 명령 완료와 과업 결과 성공의 차이를 에이전트가 추가 판단해야 함 | 일부 B 탐색은 `ok:true` 뒤 Chrome 오류 문서 또는 비어 있는 결과 화면; Walmart/Best Buy의 지속 Loading 화면 | 결과에 내비게이션 오류·렌더링 미완료·확인된 사이트 차단을 구분. 의미 있는 상태를 읽은 뒤 필요한 경우 headed 전환. 실제 쓰기는 결과 불명 상태에서 자동 반복하지 않음 |
| P1 | 새 탭 링크의 결과를 찾기 위해 추가 탐색이 필요함 | eBay B에서 클릭 후 기존 탭 URL 불변; session list와 팝업 관찰 필요. `r3_ebay_hb` 명령 022에서 팝업 viewport 929×917 | effect에 새 세션 ID와 관찰 URL을 포함하고 새 탭에도 초기 viewport/locale 준비를 적용. 늦게 생성되는 팝업 및 여러 탭 사례 검사 |
| P2 | 잘린 요소 이름이 정확 일치 locator로 안내되어 실패와 불필요한 headed 전환을 유발 | `r3_amazon_hb` 명령 011: 긴 이름 no_match, 이후 짧은 이름 ambiguous. 명령 013–014 후보 확인으로 복구 | 표시용 축약과 실행용 식별자를 분리하고, 후보 맥락을 충분히 제공. 문자열 축약으로 locator를 만들지 않도록 문서/출력 검증 |
| P2 | browser-use CLI의 초기 DOM 준비·입력 유지·스크롤/스크린샷 시간 초과가 작업 흐름에 영향을 줌 | `r1_amazon_bu`의 조기 종료와 `r2/r3_amazon_bu`의 복구 성공; Walmart/eBay/IMDb scroll IPC timeout; screenshot 60초 timeout | 도구 계층 문제와 에이전트의 호출·대기 선택을 분리해서 재현. 입력 후 값·포커스·제출 결과 확인, 긴 실행 poll 지침, helper별 오류 처리 개선 후보. SDK 전체의 결함으로 일반화하지 않음 |
| P2 | 날짜 선택은 했지만 결과는 다른 가격 기준인 사례 | `r1/r2_booking_bu`: 날짜가 초기화된 도시 목록, 1박 가격. 무료 취소 미적용 | 공통 완료 검증에서 적용 날짜·인원·필터와 읽은 가격의 기준을 함께 확인. 요소 클릭 성공을 사용자 작업 성공으로 간주하지 않음 |

후속 순서는 관찰 안정성·Windows 참조 전달·위험도 오탐을 먼저 다루고, 새 탭 전달과 결과 검증을 보강하는 것이 적절하다. 재사용 자산의 학습·수정 효과는 이번 실험에서 측정하지 않았으며 별도 설계가 필요하다.
