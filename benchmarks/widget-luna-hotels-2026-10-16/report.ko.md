## 과정에서 실제로 확인한 것

- #1 초기 지도는 쿠키 dialog의 Reject All, 본문의 Where to?/Dates를 전달했다. #2~4 거절·목적지 열기·Paris 입력. 목적지 dialog의 native.type=text와 invalid=false가 작은 focus에 전달됐다.
- #5~7 목적지 조회와 실제 Paris, France 후보 선택. #8 기존 Dates ref로 달력을 열었다. 이때 작은 dialog 정보만이 아니라 배경 banner/main을 포함한 전체 지도가 focus로 반환됐다.
- #9~11 달력의 controls,content를 offset0/60/120으로 읽었다. 세 응답만22,810B(전체의 약49%)였다. 요일·비활성 날짜·aria-hidden 래퍼가 대부분을 차지했고 관찰 노드는286→582→667로 늘었다. 서로 다른 시점의 live read이므로 이를 하나의 정적 페이지 총계로 합치지 않는다.
- #12 명령 인자가 `--query Next month`로 분리돼 실제 query가 Next만 됐다. #13 임의 goal-id `G???`는 invalid_goal_id로 거부됐다. 이는 제품의 달력 탐색 실패와 별개인 호출 생성 문제다.
- #14 스크린샷은 열린 달력, October2026, 내부 스크롤바를 보여준다. Luna가 실제 열람했고 분석자도 별도로 열람했다.
- #15 루나는 panel/at 없이 scroll down700 times2를 요청했다. 실제 owner=document, scrollY0→1091이었다. 이후 currentView에는 달력이 없었고, #16 이전 ref 클릭은 stale_ref/not_started로 안전하게 거부됐다. 새 패널 스크롤 API 자체를 호출하지 않았으므로 이 시험을 그 API의 동작 실패라고 기록하지 않는다.
- #17 날짜 문자열도 인자가 나뉘었다. 찾기는 실패하고 자동 시각 fallback이 홈페이지 본문 이미지를 반환했다. Luna는 이 이미지도 열람했다고 사후 확인했다. #18 다시 문서를 맨 위로 올렸다. #19 snapshot은 아직 visual_review_required로 거부됐다. #20 visual-reviewed를 전달해 현재 Dates 버튼을 unique로 재발견했다.
- **#20은 복구 가능한 상태였다.** 하지만 #21 Luna가 session close로 끝냈다. 45호출/8분 예산이 남아 있었고, Luna도 성급한 종료 판단이었다고 확인했다. 앱만의 불가피한 실패로 해석하지 않는다.

원시 result-agent.json에는 screenshotPath가 #14 하나만 기록돼 사후 설명의 시점이 불완전하다. #14는 달력 열림, #17의 V03ab309619e33145는 홈페이지 본문이다. 두 장을 구별해 해석한다. 중간에 분석자가 인용/JSON 사용과 실제 이미지 열람 여부를 확인하는 메시지1회를 전달했다. 완전 무개입 성능 측정은 아니다.

## 공통 개선 후보

1. 달력·표처럼 반복 셀이 많은 작업면은 첫 응답에 현재 제목·선택값과 실제 스크롤 범위의 실행 가능한 진입점을 제공해야 한다. 새 panel scroll이 존재하는 것과 에이전트가 바로 사용하는 것은 다르다. 사이트별 날짜 규칙으로 해결하지 않는다.
2. 조작 조회에서 controls와 content 전체 순회를 구별하고, 월 이동/확정 컨트롤을 찾으려는데 비활성 날짜·래퍼 수백 개를 먼저 읽게 하지 않는다. 이번 출력의 주요 낭비는 이 지점이다.
3. 내부 스크롤 작업면에서 범위 없는 scroll이 들어오면 모호함을 드러내거나 명시적 범위 선택을 돕는 계약을 검토한다. 임의로 달력이라고 판단해 대신 움직여서는 안 된다.
4. 실행 가능한 현재 후보를 다시 찾았다면 fallback을 받았다는 이유만으로 종료하지 않는다. 남은 과업과 예산에 맞춰 복구한다. 긴 스킬 경고를 추가하기보다 현재 응답의 next와 예제·호출 스키마를 점검한다.
5. 다단어 shell 인용·유효 goal-id·최대4개 배치를 실제 수행자가 지키는지 별도로 본다. 이번에는 run이 없었으며 전략 전체가 실전에서 검증됐다고 말할 수 없다.
