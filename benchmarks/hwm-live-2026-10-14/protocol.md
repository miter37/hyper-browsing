# HWM 0.2 실전 단회 테스트

2026-10-14. 사용자 지시에 따라 Wikipedia, eBay, GitHub Issues, MDN, Hacker News, Booking.com 각 1회, 총 6회. Luna 에이전트 한 명씩 순차 수행하며 끝난 즉시 다음 사이트를 시작한다. 비교군과 반복 시행은 없다.

- 개발 브랜치: feat/hwm-0.2, 기반 커밋 fb23f9eaf792f38d13c2e7589a49f87d2330b188. 작업 트리의 HWM 단계 4 구현을 사용한다.
- 수행 모델: gpt-6-luna, medium. 사이트마다 새 에이전트와 빈 managed 프로필, 독립 데몬을 사용한다.
- 개발 프로젝트 HB CLI만 사용. HWM overview/expand/inspect/focus 우선. 부족할 때 HB eval만 허용하고 용도와 이유를 기록한다.
- 학습·사이트 자산 생성 및 수정 금지. 실험 중 제품 코드 수정 금지.
- headless 시작. 접근 제한 시 headed 전환 한 번 허용. CAPTCHA 우회와 로그인은 하지 않는다. 차단 시행은 교체하지 않는다.
- 요청 창 크기 1440×900, en-US, 머신 시간대 Asia/Seoul. 실제 viewport는 각 HWM 헤더에 기록되며 대부분 1424×805, HN은 명시한 1440×900이다. 완전히 동일한 viewport로 주장하지 않는다. 미국 IP를 보장하지 않는다.
- 사이트당 최초 HB 명령부터 8분, 최대 45개 CLI 명령. 준비·정리 시간은 별도로 기록한다.
- 원시 명령 출력과 시간은 .runtime/hwm-live-20261014/<site>-1/에 저장한다. 외부 보고에는 근거와 요약을 사용하며 개인 브라우저 프로필은 사용하지 않는다.
- 명령 수는 CLI 호출 수다. 조작·조회·환경·정리를 구분한다. 각 호출의 전체 소요 시간은 LLM 사고 시간이 아니다. 명령 사이 시간 역시 사고 시간으로 단정하지 않는다.
- 실행 completed와 과업 성공을 구분한다. 각 답의 근거, 범위, 불명확성, 실제 어려움을 기록한다.
- 표본은 사이트별 n=1이므로 개선율이나 반복 신뢰도를 추정하지 않는다.

과업은 사용자가 제공한 6개 사이트 질문을 그대로 수행한다. 각 사이트의 결과는 준비되는 즉시 사용자에게 한국어로 전달하고, 마지막에 집계 보고한다.
