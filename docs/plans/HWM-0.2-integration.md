# HWM 통합 — 승인된 실행 범위

사용자 승인: 2026-10-14. 기존 기능과 HWM 정보를 한 관찰 모델에서 유기적으로 전달한다. 기존 JSON에 필드를 억지로 붙이는 두 탐색 방식은 제공하지 않는다. 이번 구현은 기존 0~4단계의 통합 보완까지이며, 추가 공간 계산인 5단계에 들어가기 전에 커밋·푸시한다. main은 변경/병합/푸시하지 않고 feat/hwm-0.2를 origin으로 일반 푸시한다.

1. 변경 전 수집/출력 기준선을 보존하고 기존 정보 보존표와 회귀 테스트를 만든다.
2. 기존 수집과 문맥 모델을 통합한다. 기본 JSON/RPC도 동일 관찰을 기반으로 하며, LLM 출력은 그 관찰의 HWM 표현이다. 기존 이름/출처/힌트/팝업/숨김/후보/클리핑/상태/오류를 잃지 않는다.
3. 기본 관찰은 선택된 실행 요소와 query 일치/본문/폼/항목/열린 대화상자 맥락을 먼저 확보한다. 같은 DOM 사실의 중복 측정과 장식 래퍼 직렬화를 줄이고 원래 소속·순서를 보존한다. 전체 수집이 아닌 범위는 명시한다.
4. 검색 일치 후보 우선 투영, 저장된 문맥 조회, 공통 출력과 CLI 형식 정책을 연결한다. JSON은 전송/스크립트 호환이며 별도 관찰 엔진이 아니다. 원시 상태의 의미를 HWM에 맞추려고 바꾸지 않는다.
5. 매 입력/클릭의 전후 전체 그래프 수집을 없애고 기존 실행효과와 필요한 주변 관찰을 쓴다. 요청한 상세 diff는 명시적으로 수집한다. 실행 결과 불명 상태를 재전송하지 않는다.
6. 0.2 문서/명령/에이전트 직접 범례와 구현 기록을 수정한다. 이전 발견은 삭제하지 않는다. 새로운 5단계 이후는 같은 관찰의 저비용 위치/관계 보강→범위 기반 비용검증의 순서로 작성하되 이번에는 구현하지 않는다.
7. 기존 전체 테스트와 정보 보존/후보우선/민감정보/스크롤·미수집 경계/통신 회귀, 변경 전후 비용 검증을 실행한다. 수집 중앙값+15%, p95+25%를 목표로 하고 실패시 추가 수집 범위를 최적화한다.
8. 마지막 브랜치 전체 리뷰와 필수 검사 후 관련 변경만 커밋하고 origin/feat/hwm-0.2에 푸시한다. 원시 프로필/토큰/개인정보는 포함하지 않는다. 새 실전 수행은 Luna 한 명씩 각1회/학습OFF이며 5단계 개발과 구분한다.

## 결정 기록

- 기존 작업 트리의 HWM0~4 구현/검증/문서는 보존하여 통합한다. 새 worktree로 미커밋 내용을 유실시키지 않는다.
- 브라우저 원시 관찰의 사실은 한 번 만들고 정본/스크립트JSON/LLM 문법은 같은 사실을 투영한다. 세부 디버그 조회 기능은 유지하지만 LLM의 별도 필수 탐색 루프로 강제하지 않는다.
- 기존 파일 변경은 사용자 승인 범위 안에서만 통합한다. 설치된 별도 스킬 사본은 변경하지 않는다.

## 통합 구현 기록

- 기본 capture에서 기존 요소/문맥을 함께 수집하고 CLI HWM/overview를 기본값으로 연결했다. JSON 호환, 관리/inspect JSON은 유지했다.
- 빈 래퍼 수집 압축, 동일 스타일/rect 재사용, 선형 제목 개요, 메타정보/WeakRef 지연 바인딩으로 추가 비용을 줄였다. 기존 실행 guard와 epoch 수명 계약은 유지했다.
- 일반 조작의 새 전체 실행 전 수집을 제거했다. 보유 이전 관찰 + 대상 주변 조작 후 관찰을 비교한다. 조회 데이터의 TTL/메모리 제한을 재사용하며 별도 무제한 캐시는 두지 않았다.
- 최종 신선한 리뷰가 재현한 Important 4건: forms undefined 직렬화, forms 민감값/URL 정책 불일치, textarea discovery 누출, 예산 뒤 본문 query 유실. 일반 HTML 회귀로 재현 후 공통 정책/선택 예약을 수정했다. 사이트 이름 분기를 넣지 않았다.
- Ruling: 기존 파생 hint/context와 discovery를 출처가 명시된 같은 문법에 보존한다 — 원래 능력과 정보를 잃지 않기 위함 — 잘못 읽으면 파생 문구를 DOM 선언으로 오인할 수 있으므로 출처를 표시한다.
- Ruling: 보유 이전 관찰은 실행 직전 상태라고 주장하지 않는다 — 전체 이중 수집 비용을 피하면서 확인한 사실만 비교 — intervening changes의 원인은 확정하지 않으며 incomparable을 정상 정보로 둔다.
- Ruling: 명시하지 않은 overview 예산보다 기존 선택 요소·조상·본문 일치를 우선한다 — 선택된 대상이 투영에서 사라지는 일을 막음 — 큰 화면은 출력량이 늘 수 있으며 예산/접힘으로 드러낸다.
- Ruling: 내부 정본 및 JSON은 같은 관찰의 호환 표현이다 — 제품에 두 브라우징 방식을 만들지 않음 — 기존 기본 JSON 파서는 --format json 또는 환경변수 설정이 필요하다.
