# 승인된 실험 기반 개선 구현 기록

범위: hyper-browsing만 개선. browser-use·기존 실험 결과·학습 빈도는 변경하지 않는다. 자동 커밋·배포 없음.

1. 방어적인 DOM 순회, 부분 관찰과 별도 CAPTCHA 탐지.
2. PowerShell 안전한 e숫자 참조, @e 입력 호환, 표시 이름 축약과 내부 의미 locator 분리.
3. 실제 고정 요소에 기반한 위험도, 검색 오탐 수정 및 CSS/Enter/제출 보호.
4. 페이지 상태와 환경 실패 기반 headed 전환. 쓰기는 재실행하지 않는다.
5. 부모 설정을 적용한 새 탭 즉시 등록·effect 전달. 저장 후속 단계 중단.
6. 읽기 전용 verify: 최대20조건·5초·전체 조건 근거·3상태 판정. 학습 없음.

검증: 기존 npm test + 새 회귀 테스트, 별도 코드 리뷰, 학습을 끈 10사이트×3 독립 Luna 시행. 기존 60회 보고서와 동결 소스는 보존한다. 실사이트 CAPTCHA는 실패 근거로 기록하되 우회하지 않는다.

기준 상태는 원래 프로젝트의 미커밋 작업 트리를 격리 공간에 복사한 것이다. 변경 반영 전에 파일별 SHA256을 비교해 다른 변경을 덮어쓰지 않는다.
