# 공통 실행과 일회성 도구 구현 기록

- [x] 저장된 선언형 액션의 모호한 첫 요소 선택 제거, 공통 입력 확인·효과 보고 연결
- [x] 실제 DOM 요소에 연결되는 세션 한정 참조, 재정렬·교체·탐색 회귀 테스트
- [x] 공통 RPC 전송과 outcome_unknown, 요청 ID·결과 조회·동일 요청 중복 실행 방지
- [x] 입력·선택 전용 임시 배치, 형식 사전 검증·실패/구조 변화 시 중단
- [x] 기본 간결 출력과 명시적 상세 조회, 스킬 문서 분리
- [x] 전체 테스트와 최종 코드 검토

결정: 코드 액션의 raw Playwright 경로는 호환성을 유지한다. `ctx.act`를 공통 경로로 제공하며 임의의 사용자 코드를 자동 재작성하지 않는다.
결정: 배치는 트랜잭션이 아니다. 입력을 롤백하거나 전체 배치를 자동 반복하지 않는다.
결정: 요청 캐시는 로컬 데몬 메모리에서 최대 512개·5분 범위다. 만료·재시작으로 결과가 없을 때도 미실행으로 간주하지 않는다.
결정: 이전 학습 변경과 사용자 파일은 보존하며 자동 커밋·푸시는 수행하지 않는다.

문서 기준 검사: 기존 SKILL만 읽은 별도 에이전트가 요소 참조·배치·요청 상태 조회 명령의 누락을 확인했다. 새 문서 적용 후 동일 시나리오를 다시 확인한다.

완료 확인: 새 문서의 세 시나리오 재검토를 통과했다. 요청 오류의 ID 출처와 partial 상태 설명을 보완했다. 최종 리뷰에서 확인한 재사용 행 참조와 실행 거부 후 잘못된 승격을 회귀 테스트로 재현하고 수정했다.

검증: `npm test` 통과 — 타입 검사, 학습 34개, 실행·통신 14개, Chrome 관리 시나리오 15개, 탐색 46개. 브라우저 검증은 로컬 HTML과 실제 Chrome을 사용했으며 외부 서비스의 호환성을 보장하는 결과는 아니다. 실행 중인 기존 데몬에는 재시작 후 새 코드가 적용된다.
