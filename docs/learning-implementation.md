# 학습 정책 구현 기록

목표: 작업 종료와 학습을 분리하고 최근 30일 2작업부터 액션, 7작업부터 얕은 탐색 러너를 지원한다. 기존 자산이 깨지면 재탐색 성공 후 최소 수정하고 현재 버전의 증거를 새로 쌓는다.

- [x] 로컬 방문·노하우·종료 판단 및 보관 한도
- [x] 버전별 증거와 실패 자산 보류·복구
- [x] 제한된 탐색 러너와 액션 저장 인터페이스
- [x] CLI/RPC와 에이전트 지침 연결
- [x] 회귀 테스트·타입 검사·검토

결정: 사용자와 공유한 현재 체크아웃에서 구현하며 자동 커밋·푸시는 하지 않는다. 기존 러너와 사이트 정의는 보존한다.
결정: 엔진은 정책, 증거, 제한, 복구 상태를 제공하고 재탐색·코드 수정은 에이전트가 수행한다. 백그라운드 LLM 생성은 추가하지 않는다.
결정: 신규 사이트 노하우와 방문은 로컬에 저장한다. 실행 액션은 기존 YAML 형식을 사용하며 사용자별 입력값은 영구 정의에 저장하지 않는다.

결정: 액션 저장 API의 자동 재실행 검증은 부작용 없는 추출 전용 선언형 액션에 한정한다. 클릭·입력·코드 절차는 다음 승인된 실제 작업에서 검증한다. risk=read만으로 재실행 안전성을 가정하지 않는다.
결정: 선언형 액션은 실제 참조 정의만 해시에 포함한다. 코드 액션은 임의의 공유 정의를 사용할 수 있으므로 공통 코드와 공유 정의를 보수적으로 포함한다.
결정: 동시 실행 중 다른 성공이 기존 보류를 해제하지 않는다. 수정본 검증과 승격은 정확히 같은 저장 버전일 때만 수행한다.

검토: 별도 읽기 전용 리뷰에서 발견한 자동 검증 재실행, 환경 오류 오인, 동시 실행 보류 해제, 누락된 코드 파일 복구, YAML 업데이트 경쟁, 수정본 검증·승격 경쟁을 회귀 테스트로 확인하고 수정했다. 마지막 집중 검토에서 남은 P1 문제는 발견되지 않았다.
검증: 새 학습·복구 테스트, 타입 검사, Chrome 관리 시나리오 15개와 기존 탐색 도구 검사 46개를 수행한다. 사이트 정의 7개의 기존 검증 실패는 이번 변경의 범위에서 제외하고 기존 파일을 보존한다.
