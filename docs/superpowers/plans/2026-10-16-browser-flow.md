# 브라우저 전환과 국소 관찰 보완 계획

> 실행: 이 세션에서 직접 구현한다. 사용자가 승인한 네 보완을 순서대로 적용한다.

**Goal:** 정상적인 SPA 이동과 입력 간격 때문에 계획이 끊기는 일을 줄이고, 필요한 후속 결과를 작은 출력으로 전달한다.

**Architecture:** 실행 ref는 실제 Document 수명과 DOM/의미 가드를 따른다. 입력 간격은 목표 탐색 전에 한 번 적용한다. 후속 조회는 명시한 목표와 연결된 새 영역을 제한적으로 기다린다. 정본을 보존하며 읽기 투영만 줄인다.

**Spec:** docs/GOOGLE-MAPS-PRACTICE-2026-10-16.md 후속 조사 및 사용자 ‘어 다 반영해줘’ 승인.

**제약:** 사이트별 예외 없음. 공통0.5~1초 입력 간격 유지. 완료/unknown 재실행 금지. 명시ref를 다른 대상으로 대체하지 않음. 이름·위험·범위 가드 유지. 기본 출력 증량 억제. 현재 브랜치와 미커밋 변경을 보존한다.

- [x] `references.ts`: pushState/replaceState/hash에서 Document 동일성 확인 후 ref 유지. 실제 reload/교체는 폐기. read scope는 URL 변경과 별도로 보호한다. `hwm-references`, `demand-observation`에 회귀.
- [x] `task/run.ts`, `interact.ts`: 목표 탐색 전 공통 입력 간격을 적용하고 내부 실행에서 중복 대기하지 않는 내부 전달 경로. 기한/모호함/현재상태 검사 유지. 지연 중 DOM 교체 fixture.
- [x] `task/observe.ts`, `recovery.ts`: 후속 목표가 없거나 명시 연결 영역이 아직 닫혀 있으면 제한시간 안에서 읽기만 기다린다. 연결 영역 밖 기존 후보를 새 메뉴 내용으로 반환하지 않는다. 미확인/부분 상태와 원래 실행 결과 분리.
- [x] 읽기 투영: 정본과 explain은 유지. 이름으로 이미 전달한 컨트롤의 동일 텍스트, 확인된 숨은 장식 구조, aria-hidden 아이콘을 줄이고 축약 수를 명시한다. 항목·행·관계 종점·상태·질의 일치 보존. `demand-observation` 회귀.
- [x] SKILL/COMMANDS를 기존 절차에 통합하고 공통 발견 기록. 타입검사/관련 회귀 후 전체 표준 테스트. 실사이트 대규모 재시험은 하지 않는다.

판단: 동일 문서 URL 변경에서 실행 ref는 유지해도, 이전 지도/범위 핸들을 새 화면으로 조용히 재사용하지 않는다. 범위 핸들은 URL 전환 시 만료 처리한다. 이는 실행 대상과 관찰 범위의 수명이 다르다는 계약이다.
