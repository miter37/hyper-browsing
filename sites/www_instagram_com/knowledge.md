# 인스타그램 (Instagram) 웹 자동화 가이드

## 1. 이미지 업로드 및 비율 제어 (Upload & Aspect Ratio)
- **복수 이미지 업로드**:
  - 파일 인풋(`input[type="file"]`)은 화면에 직접 노출되지 않음.
  - CDP `DOM.describeNode`를 통해 `backendNodeId`를 획득한 뒤 `DOM.setFileInputFiles`에 파일 경로 배열을 넘겨 여러 장의 사진을 한 번에 주입.
- **디폴트 '원본' 크기 강제 설정**:
  - 첫 번째 자르기 화면에서 좌측 하단 `svg[aria-label="자르기 선택"]` 아이콘을 클릭.
  - 드롭다운 메뉴의 첫 번째 항목인 **'원본'**을 클릭해야 1:1 정사각형 강제 크롭 없이 와이드/세로 원본 비율이 보존됨.

## 2. 캡션 입력 및 게시물 라이프사이클 (Post Lifecycle)
- **캡션 입력**:
  - '다음' 버튼을 2회 통과한 후 `div[role="textbox"][contenteditable="true"]`에 CDP `Input.insertText`로 문구 입력.
- **게시물 수정 (Edit)**:
  - 프로필 그리드에서 게시물 오픈 -> 우측 상단 `svg[aria-label="옵션 더 보기"]` (점 3개) 클릭.
  - 메뉴에서 `수정` 버튼 클릭 -> 문구 편집 후 `완료` 클릭.
- **게시물 완전 삭제 (Delete)**:
  - `옵션 더 보기` -> `삭제` 클릭 -> 팝업에서 확인용 빨간색 `삭제` 버튼 클릭 -> 그리드에서 즉시 제거됨.

## 3. 댓글 및 인터랙션 주의사항 (Critical Interaction Rules)
- **댓글 작성 시 주의점 (피드 vs 상세 모달)**:
  - 홈 타임라인 피드 상의 더미 댓글창은 포커스가 빗나가거나 전송이 씹히는 경우가 많음.
  - **반드시 말풍선 아이콘(`svg[aria-label="댓글 달기"]`)을 눌러 상세 뷰(모달 다이얼로그)로 진입한 후 작성**해야 함.
  - 모달 내부의 `textarea`에 텍스트 입력 후 활성화되는 파란색 **`게시`** 버튼을 클릭해야 실제 댓글 리스트에 즉시 반영됨.
- **좋아요**: 피드 상단 `svg[aria-label="좋아요"]` 클릭으로 즉시 반영.
- **팔로우**: 사이드바 추천 목록의 `팔로우` 버튼 클릭으로 즉시 처리.
